# Privacy policy

*Last updated: 21 October 2026*

Knight Family Organiser is a private tool used by one family to manage its own Google Calendar. This page explains what it accesses and what it does with it.

## What it accesses

With the account owner's permission, given through Google's sign-in screen, the tool can:

- see the list of calendars in the owner's Google account
- read, add, change and remove events in calendars the owner has chosen
- see the email address of the signed-in account, so it can confirm it's the right account

It doesn't access email, contacts, files, photos or any other Google data.

## What it does with it

- Events are only added or changed when the owner runs the tool and approves the changes.
- It only changes or removes events it created itself.
- Sign-in credentials are stored on the owner's own computer and nowhere else.
- No data is sent to any server other than Google's.
- No data is sold, shared, used for advertising, or used to train any AI model.
- There are no analytics, tracking or cookies.

## Google API Services User Data Policy

The tool's use of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

## Removing access

The owner can remove the tool's access at any time from [Google Account permissions](https://myaccount.google.com/permissions). Deleting the stored credentials from the owner's computer removes them completely.
